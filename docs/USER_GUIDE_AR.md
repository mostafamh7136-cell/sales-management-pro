# دليل المستخدم
١. أنشئ حساباً واختر نشاطك. ٢. المنتجات: سعر وتكلفة ومخزون وباكود وانتهاء. ٣. الكاشير: أصناف وخصم وتوصيل ودفع وتقسيط — حفظ على الخادم بدون مخزون سالب. ٤. إلغاء وإرجاع يعيدان المخزون. ٥. الديون والسداد. ٦. تقارير وتصدير. ٧. إيصال وواتساب. ٨. إعدادات ونسخ احتياطي. مبيعات دون اتصال تُزامَن تلقائياً.
